# ACWR（急慢性负荷比）计算方法技术文档

> 运动员管理系统（AMS）· 伤病与负荷监控模块
> 文档版本：v1.0（2026-08-06）

## 1. 概述

急慢性负荷比（Acute:Chronic Workload Ratio, ACWR）用于量化运动员近期训练负荷相对长期训练基准的变化程度，是运动科学中预防过度训练与运动损伤的常用指标。

本系统 ACWR 采用 **EWMA（Exponentially Weighted Moving Average，指数加权移动平均）** 方法计算，区别于简单的滚动求和法：EWMA 对近期负荷赋予更高权重，对训练刺激变化更敏感，能更早发现负荷骤增或骤减的风险信号。

## 2. 训练量定义（sRPE 方法）

单次训练负荷（训练量）采用 **session-RPE** 方法计算：

```
训练量（AU）= 自觉劳累程度 RPE（1-10）× 训练时长（分钟）
```

- RPE：运动员自觉劳累程度评分，1-10 整数（1=极轻松，10=力竭）
- 训练量单位：AU（Arbitrary Unit，任意单位）

每日训练量为当日所有训练记录训练量之和。

## 3. 急性负荷与慢性负荷（EWMA）

### 3.1 衰减因子 λ

EWMA 的衰减因子由窗口长度 N 决定：

```
λ = 2 / (N + 1)
```

| 窗口 | 天数 N | λ | 含义 |
| --- | --- | --- | --- |
| 急性负荷 | 7 | 0.25 | 近 1 周的短期训练刺激 |
| 慢性负荷 | 28 | 2/29 ≈ 0.069 | 近 4 周的长期训练基准 |

### 3.2 递推公式

对窗口内第 t 天的每日训练量 `Load(t)`：

```
EWMA(0) = Load(0)                 // 以窗口首个观测值初始化
EWMA(t) = Load(t) × λ + EWMA(t-1) × (1 - λ)
```

要点：

- **初始化**：以窗口首个观测值作为初始 EWMA。
- **零负荷日**：无训练记录的日子按 0 参与递推，EWMA 以 `(1 - λ)` 的速率自然衰减，体现训练负荷随时间的"遗忘"。
- 急性 EWMA 基于近 7 天序列计算，慢性 EWMA 基于近 28 天完整序列计算。

## 4. ACWR 计算

```
ACWR = 急性 EWMA（近 7 天） / 慢性 EWMA（近 28 天）
```

- 结果保留两位小数。
- **有效性判定**：当慢性 EWMA ≤ 0 或任一 EWMA 为非有限数值时，ACWR 视为无效（`null`），风险等级降级为「暂无数据」。

## 5. 风险分级阈值

系统严格依据 ACWR 数值进行风险等级判定，阈值与视觉标识如下：

| ACWR 区间 | 等级 | 视觉标识 | 标准化评价文本 |
| --- | --- | --- | --- |
| < 0.8 | 负荷不足（LOW） | 绿色 | 近期的训练刺激较少（急性工作量），或运动员训练不够（慢性工作量较低）；这种情况下受伤的可能性较高 |
| 0.8 - 1.3 | 舒适区（SAFE） | 黄色 | 这一范围代表训练条件适中，受伤风险最小（舒适圈） |
| 1.3 - 1.5 | 风险升高（ELEVATED） | 橙色 | 训练负荷上升较快（急性工作量高于慢性负荷基准），受伤风险升高，建议调整训练安排并持续观察 |
| > 1.5 | 高风险（HIGH） | 红色 | 运动员处于超负荷状态（急性工作量更强烈）；这个区间的受伤概率最高（危险区） |
| 无有效数据 | 暂无数据（NO_DATA） | 灰色 | 暂无足够的负荷数据计算 ACWR，请录入训练负荷（RPE × 训练时长）后重新评估 |

**排序规则（风险预警）**：按风险优先级 `HIGH > ELEVATED > LOW > SAFE > NO_DATA` 排序，同级按 ACWR 降序。

## 6. 数据来源与验证机制

### 6.1 数据来源

- 负荷记录由医务人员/管理员在「伤病与负荷监控 → 负荷监控」中录入，或通过数据看板「快捷操作」快速跳转录入。
- 每次录入校验：RPE 必须为 1-10 整数、训练时长必须大于 0、运动员必须存在。

### 6.2 验证机制

系统在计算与返回链路中设置了多重数据校验：

1. **录入校验**：`createLoadRecord` 校验 RPE 与训练时长合法性。
2. **聚合校验**：`getLoadOverview` / `getAthleteLoadDetail` 在聚合每日训练量时跳过非法记录（训练量为非有限值或负数）。
3. **计算校验**：`computeAcwrRatio` 仅在急性/慢性 EWMA 均为有限数值且慢性 EWMA > 0 时返回比值，否则返回 `null`。
4. **输出校验**：`validateAcwrValue` 校验 ACWR 数值非空、有限且非负；`GET /api/health/load/risk-summary` 在返回前对每个 ACWR 执行该校验，非法值统一降级为「暂无数据」，确保前端展示的预警结果始终有效。

## 8. 局限与使用建议

- ACWR 是基于训练负荷的间接风险评估，不替代医学诊断；结合伤病记录、体能测试等数据综合研判。
- EWMA 初始化对数据稀疏的窗口较敏感，建议连续记录至少 2-3 周负荷后参考 ACWR。
- 阈值（0.8 / 1.3 / 1.5）基于通用运动科学文献建议，可根据团队实际训练特征在代码中调整（见 `LoadService.ts` 中 `ACWR_LOW_MAX` / `ACWR_SAFE_MAX` / `ACWR_ELEVATED_MAX`）。
